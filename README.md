# Teaser Multiplicai

Este é o projeto de teaser para a Multiplicai — um site estático de apresentação institucional leve, com HTML, CSS e JS puros.

## ✨ Objetivo

Criar uma presença inicial na web enquanto o website completo está em desenvolvimento.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Foundation Framework (CSS Grid e utilitários)
- Google Fonts
- Google Tag Manager

## 📁 Estrutura

- `index.html`: Página principal do teaser.
- `css/`: Estilos customizados e Foundation framework.
- `js/`: Scripts próprios e bibliotecas do Foundation.
- `img/`: Logotipo, ícones de redes sociais e imagens ilustrativas.
